# homepanel (QML prototype) - unfinished, kept as the fallback

An early QML prototype for the home control panel, written before the project moved to Swift/OpenSwiftUI
(see https://github.com/Tinnci/swift-homepanel). It contains only a design-token singleton (`Theme.qml`) and a Home
Assistant WebSocket client with demo data (`HaClient.qml`).

**Status: never run.** No screens, no `main.qml`, no tests. It was linted with `qmllint` only. It exists so the
QML fallback in the swift-homepanel roadmap has a starting point.
